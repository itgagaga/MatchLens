# MatchLens - 体育赛事数据智能统计与态势分析系统

## 项目简介

MatchLens 是一个支持多类体育赛事的数据统计、态势分析与赛后复盘系统。系统采用通用赛事模型设计，通过策略模式适配篮球、足球、排球等不同赛事的统计与分析规则，并集成 AI Agent 模块实现智能化的态势分析和赛后复盘。

## 核心特性

- **多赛事适配**：支持篮球（完整）、足球（轻量）、排球（轻量）等多种体育赛事
- **AI Agent 分析**：集成态势分析与赛后复盘的 AI 能力封装
- **设计模式驱动**：采用状态模式、责任链模式、策略模式、观察者模式等设计模式约束架构
- **通用赛事模型**：抽象 Match、Team、Player、MatchEvent 等通用实体，避免系统绑定单一赛事

## 技术栈

- **后端框架**：Spring Boot + MyBatis
- **数据库**：MySQL 8.0
- **前端**：HTML/CSS/JavaScript
- **构建工具**：Maven

## 系统架构

```
表现层 (HTML/CSS/JS)
    ↓
业务服务层 (Service)
    ↓
设计模式核心层 (State/Chain/Strategy/Observer)
    ↓
AI Agent 封装层
    ↓
数据层 (MySQL)
```

## 设计模式应用

| 设计模式 | 应用场景 | 解决问题 |
|---------|---------|---------|
| 状态模式 | 比赛状态管理 | 避免比赛状态错乱，封装不同状态下的行为 |
| 责任链模式 | 事件数据校验 | 拆分复杂校验逻辑，提升可维护性 |
| 策略模式 | 赛事分析规则 | 适配不同赛事的分析策略，支持扩展 |
| 观察者模式 | 事件联动更新 | 比赛事件后自动更新比分、统计、预警等模块 |

## 数据库设计

系统包含 5 张核心表：

- `t_match` - 比赛表
- `t_team` - 队伍表
- `t_player` - 球员表
- `t_match_event` - 比赛事件表
- `t_player_statistics` - 球员统计表（Key-Value 结构适配多赛事）

## 功能模块

### 1. 比赛管理
- 创建比赛、设置赛事类型
- 添加参赛队伍和球员
- 比赛状态控制（开始/暂停/结束）

### 2. 数据采集
- 支持多种赛事事件录入（得分、犯规、助攻等）
- 责任链校验确保数据合法性

### 3. 数据统计
- 实时比分更新
- 球员/队伍统计
- 关键指标分析

### 4. 态势分析
- 根据赛事类型选择分析策略
- AI Agent 生成实时态势分析文本

### 5. 赛后复盘
- 比赛结束后生成复盘报告
- 包含胜负分析、关键球员表现、改进建议

## 项目结构

```
matchlens

```

## 运行说明

### 环境要求
- JDK 17+
- Maven 3.6+
- MySQL 8.0+

### 启动步骤

1. 创建数据库并执行 `src/main/resources/data/matchlens.sql`
2. 修改 `application.yml` 中的数据库配置
3. 运行 `mvn spring-boot:run`
4. 访问 `http://localhost:8080`

## 赛事适配说明

| 赛事 | 实现程度 | 主要事件 |
|-----|---------|---------|
| 篮球 | 完整实现 | 得分、犯规、助攻、篮板、抢断、失误、暂停 |
| 足球 | 轻量适配 | 进球、犯规、黄牌、红牌、换人 |
| 排球 | 轻量适配 | 得分、拦网、发球得分、失误、暂停 |

## AI Agent 模块

系统集成以下 AI Agent：

- **DataCollectAgent** - 数据采集与结构化处理
- **SituationAnalysisAgent** - 实时态势分析生成
- **ReviewReportAgent** - 赛后复盘报告生成

支持本地规则模板和远程大模型 API 两种实现方式，可通过策略切换。

## 扩展指南

### 新增赛事类型

1. 在 `SportType` 枚举中添加新赛事类型
2. 创建对应的 `AnalysisStrategy` 实现类
3. 定义新赛事的事件类型和统计规则
4. 实现赛事特定的分析逻辑

无需修改核心业务代码，符合开闭原则。
